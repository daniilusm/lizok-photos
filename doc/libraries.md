# Библиотеки проекта

Подробное описание всех используемых библиотек и их назначение в проекте.

## 📦 Основные зависимости

### Next.js 15.5.3

**Назначение**: React фреймворк для продакшн-приложений с SSR/SSG

**Использование в проекте**:
- Основной фреймворк для фронтенда
- App Router (Pages Router в `src/pages/`)
- SSR/SSG для оптимизации производительности
- API Routes для серверных эндпоинтов

**Конфигурация**: `next.config.ts`

**Особенности**:
- Настроен webpack для обработки SVG через `@svgr/webpack`
- SCSS модули с автоматическим импортом helpers
- Алиасы путей для удобного импорта

### React 19.1.0

**Назначение**: Библиотека для построения пользовательских интерфейсов

**Использование в проекте**:
- Базовый UI фреймворк
- Компонентная архитектура
- Hooks для управления состоянием

**Особенности**:
- `reactStrictMode: false` в конфигурации (для совместимости с некоторыми библиотеками)

### React DOM 19.1.0

**Назначение**: Рендеринг React компонентов в DOM

### TypeScript 5.9.2

**Назначение**: Статическая типизация для JavaScript

**Использование в проекте**:
- Строгий режим типизации
- Типы для всех компонентов и утилит
- Автогенерация типов из Strapi CMS

**Конфигурация**: `tsconfig.json`

## 🎨 UI и стилизация

### react-hook-form 7.65.0

**Назначение**: Производительная библиотека для работы с формами

**Использование в проекте**:
- Формы ввода данных
- Валидация форм
- Интеграция с Zod для схем валидации

**Статус**: Установлен в проекте, готов к использованию. Рекомендуется использовать вместе с Zod для валидации.

**Пример использования**:
```tsx
import { useForm } from 'react-hook-form';
import { zodResolver } from '@hookform/resolvers/zod';
import { z } from 'zod';

const schema = z.object({
  email: z.string().email(),
  password: z.string().min(8),
});

const { register, handleSubmit, formState: { errors } } = useForm({
  resolver: zodResolver(schema),
});
```

**Рекомендации**:
- Используйте для всех форм в проекте
- Интегрируйте с Zod для валидации
- Минимальные ре-рендеры благодаря оптимизации

## 🔍 Рекомендации по использованию

### Когда использовать какую библиотеку

1. **Анимации**: GSAP для сложных анимаций, CSS transitions для простых
2. **State Management**: Zustand для глобального состояния, React state для локального
3. **Валидация**: Zod для всех схем и валидации данных
4. **HTTP запросы**: `@strapi/client` для Strapi, `ky` для других API
5. **Стилизация**: SCSS модули для компонентов, глобальные стили для общих стилей

### Best Practices

- Используйте TypeScript типы везде, где возможно
- Валидируйте данные из CMS через Zod схемы
- Используйте SCSS модули для изоляции стилей компонентов
- Применяйте GSAP для анимаций, требующих высокой производительности
- Используйте Zustand для состояния, которое должно быть доступно глобально

## 🔄 Обновление зависимостей

Для обновления зависимостей используйте:

```bash
# Проверка устаревших пакетов
pnpm outdated

# Обновление всех зависимостей
pnpm update

# Обновление конкретной зависимости
pnpm add package-name@latest
```

**Важно**: Перед обновлением основных зависимостей (Next.js, React) проверяйте breaking changes в changelog.
